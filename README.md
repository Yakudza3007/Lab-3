# Лабораторная работа №3

## Задача 1

- **Текст задачи:** Реализовать конструкторы класса `Matrix` для создания матриц согласно варианту 14: матрицу размером n на m, заполняемую диагоналями, параллельными главной диагонали, начиная с правого верхнего угла; квадратную матрицу со случайными числами, в которой каждый столбец является убывающей последовательностью; квадратную матрицу, заполненную по спирали.
- **Алгоритм решения:** Для каждого типа матрицы реализован отдельный конструктор. Элементы размещаются в соответствии с заданным порядком заполнения. Для случайной матрицы значения в каждом столбце подбираются так, чтобы соблюдался порядок убывания.
- **Тестирование:** Проверить создание всех трёх матриц на нескольких размерах. Убедиться, что элементы расположены в соответствии с заданными правилами, а спиральное заполнение работает для чётных и нечётных размеров.

**Скриншот:** `screenshots/task01`

## Задача 2

- **Текст задачи:** Вывести элементы двумерного массива таким образом, чтобы количество выводимых элементов в каждой строке соответствовало соответствующему числу последовательности Фибоначчи. Последняя строка может содержать меньше элементов, чем требуется.
- **Алгоритм решения:** Для каждой строки определяется количество элементов, которое необходимо вывести, по последовательности Фибоначчи. Затем выводится нужное количество элементов строки. Если элементов в строке меньше требуемого количества, выводятся только существующие элементы.
- **Тестирование:** Проверить работу программы на массиве с несколькими строками. Убедиться, что количество выводимых элементов соответствует последовательности Фибоначчи, а последняя строка корректно обрабатывается при недостатке элементов.

**Скриншот:** `screenshots/task02`

## Задача 3

Для транспонирования матрицы используется соответствующий метод. После выполнения операций результат выводится в виде таблицы с помощью метода `ToString()`.

## Задача 4

- **Текст задачи:** Обработать бинарный файл и найти разность первого и максимального элементов.

## Задача 5

- **Текст задачи:** Используя структуры, определить стоимость кукол для детей шестилетнего возраста. Данные должны сохраняться и считываться с использованием XML-сериализации.
